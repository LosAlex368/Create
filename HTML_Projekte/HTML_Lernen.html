Kapitel 01 · Grundlagen

Baue das Web, Tag für Tag.

HTML gibt deinen Webseiten Struktur. Lerne die wichtigsten Tags kennen, probiere die Beispiele aus und entwickle dein eigenes Verständnis für sauberen Code.

12 wichtige Tags für deinen Start

Tag-Referenz

12 Tags

<html>

Struktur

Das Wurzelelement jeder HTML-Seite. Alles andere liegt innerhalb dieses Tags.

<html lang="de">
  ...
</html>

<head>

Struktur

Enthält Informationen über die Seite, die nicht direkt im Inhalt sichtbar sind.

<head>
  <title>Meine Seite</title>
</head>

<body>

Struktur

Hier steht alles, was Besucherinnen und Besucher im Browser sehen können.

<body>
  <h1>Hallo Web</h1>
</body>

<h1>

Text

Die wichtigste Überschrift einer Seite. Verwende sie normalerweise nur einmal.

<h1>Meine Reise</h1>

<p>

Text

Markiert einen Textabsatz und sorgt automatisch für Abstand zum nächsten Absatz.

<p>Das ist ein Absatz.</p>

<a>

Navigation

Erstellt einen Link. Das Ziel wird mit dem Attribut href angegeben.

<a href="/kontakt.html">
  Kontakt
</a>

<img>

Medien

Bindet ein Bild ein. src ist der Pfad, alt beschreibt das Bild.

<img src="foto.jpg"
  alt="Ein Berg">

<ul>

Liste

Erstellt eine ungeordnete Liste. Jeder Eintrag steht in einem eigenen li-Tag.

<ul>
  <li>Apfel</li>
  <li>Birne</li>
</ul>

<div>

Struktur

Ein neutraler Container, um Inhalte zu gruppieren und mit CSS zu gestalten.

<div>
  Inhalt einer Gruppe
</div>

<form>

Formular

Gruppiert Eingabefelder und übermittelt Daten aus einem Formular.

<form>
  <input type="text">
</form>

<button>

Formular

Ein klickbarer Button für Aktionen, Formulare oder interaktive Elemente.

<button>
  Absenden
</button>

<strong>

Text

Hebt einen wichtigen Teil des Textes semantisch hervor, meist fett dargestellt.

Das ist <strong>wichtig</strong>.
